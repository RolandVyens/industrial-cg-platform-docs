# Configuration Auto-Shuffle dans Nuke

Le script compagnon Nuke (`nuke_blender_autoaov.py`) est désormais maintenu en tant qu'outil autonome dans l'écosystème de plugins Industrial 3D : **[Auto Light Shuffle](/fr/auto-light-shuffle/)**.

👉 **[Accéder au guide et à l'installation d'Auto Light Shuffle](/fr/auto-light-shuffle/)**

- **Passes prises en charge :** Passes de lobes directes/indirectes (`<lobe>_direct_<light>`, `<lobe>_indirect_<light>`), passes de lobes (`<lobe>_<light>`, `RGBA_<lobe>_<light>`) et replis `Combined_<light>` / `RGBA_<light>`.
- **Dépôt GitHub :** [RolandVyens/auto-light-shuffle](https://github.com/RolandVyens/auto-light-shuffle)

# Nuke 自动通道重组配置

配套的 Nuke 自动重组脚本（`nuke_blender_autoaov.py`）现已作为独立工具收录于 Industrial 3D 插件生态：**[Auto Light Shuffle](/zh/auto-light-shuffle/)**。

👉 **[前往查看 Auto Light Shuffle 完整指南与安装说明](/zh/auto-light-shuffle/)**

- **支持通道：** 直接/间接分量通道（`<lobe>_direct_<light>`、`<lobe>_indirect_<light>`）、分量级通道（`<lobe>_<light>`、`RGBA_<lobe>_<light>`）以及 `Combined_<light>` / `RGBA_<light>` 回退。
- **GitHub 仓库：** [RolandVyens/auto-light-shuffle](https://github.com/RolandVyens/auto-light-shuffle)

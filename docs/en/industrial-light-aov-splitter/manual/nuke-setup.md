# Nuke Auto-Shuffle Setup

The Nuke auto-shuffle script (`nuke_blender_autoaov.py`) is now maintained as a dedicated standalone tool in the Industrial 3D plugin ecosystem: **[Auto Light Shuffle](/en/auto-light-shuffle/)**.

👉 **[Go to the Auto Light Shuffle Guide & Installation Manual](/en/auto-light-shuffle/)**

- **Supported passes:** Direct/indirect lobe passes (`<lobe>_direct_<light>`, `<lobe>_indirect_<light>`), lobe-only passes (`<lobe>_<light>`, `RGBA_<lobe>_<light>`), and `Combined_<light>` / `RGBA_<light>` fallbacks.
- **GitHub Repository:** [RolandVyens/auto-light-shuffle](https://github.com/RolandVyens/auto-light-shuffle)
